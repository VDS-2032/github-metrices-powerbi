# GitHub Repository Metrics - Power BI Dashboard

## Overview
This Power BI project captures and visualizes GitHub repository metrics for the following repositories:
- cc-order-creation
- order-modification-persist
- shopping-list-creation

## Metrics Captured

### 1. Pull/Merge Requests
- **Aggregate View**: Total count of Pull Requests raised across all repositories
- **Drill-down View**: Individual developer-level PR counts per repository

### 2. Pull/Merge Rejects
- **Aggregate View**: Total count of rejected PRs across all repositories
- **Drill-down View**: Individual developer-level rejection counts per repository

### 3. Time from PR Open to Merge
- **Aggregate View**: Average time (in hours) from PR creation to merge
- **Drill-down View**: Individual developer-level time metrics per repository

### 4. Pull Requests Open Beyond Threshold
- **Aggregate View**: Count of PRs not reviewed/merged beyond 48 hours
- **Drill-down View**: List of overdue PRs with details

## Setup Instructions

### Prerequisites
1. Python 3.8+ installed
2. Power BI Desktop installed
3. GitHub Personal Access Token with `repo` scope

### Step 1: Configure GitHub Access
1. Create a GitHub Personal Access Token at: https://github.com/settings/tokens
2. Update `scripts/config.json` with your token and repository details

### Step 2: Extract Data
```bash
cd scripts
pip install -r requirements.txt
python github_data_extractor.py
```

### Step 3: Open Power BI
1. Open Power BI Desktop
2. Import the generated CSV files from the `data/` folder
3. Apply the DAX measures from `powerbi/measures.md`

## Data Refresh
Schedule the Python script to run periodically (e.g., daily via Task Scheduler or cron) to keep metrics up-to-date.
